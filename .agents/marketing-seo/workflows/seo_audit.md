## /seo_audit — SEO Audit (Real Estate Rental)

1. **Technical SEO**:
   - [ ] Sitemap.xml tồn tại và được cập nhật?
   - [ ] Robots.txt đúng cấu hình?
   - [ ] Canonical tags đúng chưa?
   - [ ] Core Web Vitals: LCP < 2.5s, FID < 100ms, CLS < 0.1?
   - [ ] HTTPS enabled?
2. **On-page SEO**:
   - [ ] Title tag: 50–60 ký tự, có keyword chính (phòng trọ, căn hộ, cho thuê)?
   - [ ] Meta description: 150–160 ký tự, có CTA?
   - [ ] H1 duy nhất mỗi trang?
   - [ ] Alt text cho ảnh phòng?
   - [ ] Internal linking hợp lý?
3. **Local SEO**:
   - [ ] Google Business Profile đã setup?
   - [ ] NAP (Name, Address, Phone) nhất quán?
   - [ ] Schema.org RealEstateListing đã implement?
4. **Structured Data**: Schema.org đã implement (RealEstateListing, BreadcrumbList, FAQPage)?
5. Tổng hợp danh sách vấn đề theo mức ưu tiên.
